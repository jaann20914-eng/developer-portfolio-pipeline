# PPT 구성표

## 지원 대상

- 회사:
- 직무:
- 공고 원문 또는 링크:
- 강조 역량:
- 제외하거나 축소할 내용:
- 목표 페이지 수:
- 원본 PPT 경로:
- 레이아웃 기준: 기존 PPT / `design/layout-spec.md` / 사용자 지정
- 디자인 토큰 모드: `preserve-existing` / `custom`
- 디자인 옵션: `none` / 사용자 선택 옵션 ID

## 페이지별 텍스트

```text
[N페이지]

페이지 제목

섹션 제목

본문
```

## 최종 점검

- [ ] 공고와 무관한 소재를 관성적으로 포함하지 않음
- [ ] 비슷한 문제 해결 사례가 반복되지 않음
- [ ] 직접 기여와 팀 성과가 구분됨
- [ ] 모든 수치에 측정 대상과 조건이 존재
- [ ] `확인 필요`와 빈 자리표시자 제거
- [ ] 자기소개 외 문구의 명사형 종결 확인
- [ ] 기존 PPT의 슬라이드 수와 레이아웃 유지
