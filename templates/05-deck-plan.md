## 페이지 구성

기본 구성: 1 표지 → 2 이력·목차 → 3 작업 방식 → 프로젝트마다 (개요·담당 기능 1장 → 트러블슈팅 1~2장 → 성과·회고 1장)

| 페이지 | 역할 | 레이아웃 ID | 소재 ID | 전달할 한 문장 | 필수 수치·근거 | 목차 쪽 범위 | 승인 상태 |
| ---: | --- | --- | --- | --- | --- | --- | --- |
| 1 | 표지 | L01 | PROFILE |  |  | — | 대기 |
| 2 | 이력·목차 | L02 | PROFILE |  |  | — | 대기 |
| 3 | 작업 방식 | L03 | WORK-PROCESS |  |  | p.03 | 대기 |
| 4 | 프로젝트 1 개요·담당 기능 | L04 | OVERVIEW-01, CONTRIB-01 |  |  | p.04-07 | 대기 |
| 5 | 프로젝트 1 트러블슈팅 | L05 / L06 | TS-01 |  |  | (위 범위에 포함) | 대기 |
| 6 | 프로젝트 1 트러블슈팅 | L05 | TS-02 |  |  | (위 범위에 포함) | 대기 |
| 7 | 프로젝트 1 성과·회고 | L07 | RETRO-01 |  |  | (위 범위에 포함) | 대기 |

- `목차 쪽 범위`는 프로젝트의 첫 페이지 행에 `p.시작-끝`으로 적고, 이 값을 L02 목차에 그대로 쓴다.
- 트러블슈팅 2건이 짧으면 한 장(L06)으로 합치고 쪽 범위를 다시 계산한다.

## 최종 점검

- [ ] 공고와 무관한 소재를 관성적으로 포함하지 않음
- [ ] 비슷한 문제 해결 사례가 반복되지 않음
- [ ] 직접 기여와 팀 성과가 구분됨
- [ ] 모든 수치에 측정 대상과 조건이 존재
- [ ] `확인 필요`와 빈 자리표시자 제거
- [ ] 자기소개 외 문구의 명사형 종결 확인
- [ ] 제목이 `프로젝트명: 결과 또는 수치` 형식
- [ ] 회귀·사이드 이펙트 확인 결과가 트러블슈팅마다 있고, 남은 한계는 노트로 이동
- [ ] 빈 섹션 없음 (대외 성과가 없으면 섹션째 생략)
- [ ] 목차 `p.시작-끝` 범위가 실제 페이지와 일치
- [ ] 발표자 노트의 `[N페이지]` 표기가 실제 페이지와 일치
- [ ] 차트 값이 `03-1 결과`·회고 본문 수치와 일치
- [ ] 제목·본문·도식의 용어가 통일됨
- [ ] 허용한 작업 모드 밖의 변경 없음 (`text-only`이면 슬라이드 수와 레이아웃 유지)
- [ ] PowerPoint 화면으로 확인했는지, 렌더링으로만 확인했는지 기록
