# 기존 PPT에 텍스트 적용

## 입력

- 원본 PPTX 경로
- 승인된 페이지별 텍스트
- 페이지별 소재와 섹션 대응표
- 포트폴리오 문구 작성 기준
- 레이아웃 명세
- 디자인 토큰
- 사용자가 선택한 경우에만 디자인 옵션

## 적용 규칙

1. 원본을 덮어쓰지 않고 새 파일로 저장
2. 슬라이드 수·순서·레이아웃·도형·이미지·색상 유지
3. 승인된 텍스트만 교체
4. 제목, 섹션 제목, 본문, 수치 영역의 역할 유지
5. 빈 자리표시자와 `확인 필요` 제거
6. 공간이 부족하면 우선순위가 낮은 설명을 압축하고 핵심 수치와 비교 대상 유지
7. 자동 맞춤으로 글자를 지나치게 줄이기 전에 문장 압축
8. `token_mode: preserve-existing`이면 기존 PPT의 글꼴·크기·굵기·간격·색상을 유지
9. `active_option: none`이면 디자인 옵션을 적용하지 않음

## 권장 중간 산출물

```text
[6페이지]
source_material: TS-01
title: ...
section_problem: ...
section_change: ...
section_result: ...
```

텍스트 박스가 자동으로 정확히 대응되지 않으면 슬라이드별 도형 번호와 역할을 별도 매핑한다.

## 검증

- 모든 슬라이드 렌더링
- 텍스트 잘림·겹침·과도한 축소 확인
- 제목과 본문이 바뀐 위치 확인
- 숫자, 단위, 감소율의 원문 대조
- 원본 대비 의도하지 않은 도형·이미지·레이아웃 변경 확인
- 최종 PPT에서 텍스트를 다시 추출해 승인 원고와 대조
