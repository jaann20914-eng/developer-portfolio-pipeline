# 채용 공고별 소재 선별 프롬프트

입력 (저장 방식에 따라 하나를 고른다):

- 방식 1 · Notion: `채용 공고` 레코드, `프로젝트`·`포트폴리오 소재` 데이터베이스
- 방식 2 · md 파일: `workspace/_jobs/<job>/07-job-posting.md`, `workspace/_profile/`의 공통 소재, 각 프로젝트 폴더의 소재 파일 (속성 블록이 `상태: 승인`인 파일만)
- 목표 PPT 페이지 수

두 방식 모두 소재의 역할·강점·영향·기술·증거 수준은 속성(Notion 속성 또는 파일 맨 위 속성 블록)에서 읽고, 근거는 본문에서 확인한다.

작업:

1. 공고에서 반복되거나 실제 업무로 제시된 역량, 문제 유형, 기술을 추출한다.
2. 우대사항보다 필수 업무와 책임을 우선한다.
3. 소재별로 아래 기준을 평가한다.
   - 공고의 문제 유형과 연결되는가
   - 직접 기여인가
   - 코드·테스트·측정 근거가 있는가
   - 결과와 한계를 함께 설명할 수 있는가
   - 다른 선택 소재와 서사가 중복되지 않는가
4. 목표 분량에 맞춰 소재를 선택하고 제외 이유도 남긴다.

권장 점수는 의사결정 보조 수단이다.

```text
공고 핵심 역량 일치 0~3
문제 유형 일치      0~3
주요 기술 일치      0~2
직접 기여           0~2
증거 수준           0~3
정량·명확한 검증    0~1
유사 소재 중복      0~-2
```

점수가 높아도 근거가 약하면 주장의 강도를 낮춘다. 공고에 맞춘다는 이유로 경험, 역할, 수치를 새로 만들지 않는다.

출력:

- 공고 핵심 요구 3~6개
- 선택 소재와 선택 이유
- 제외 소재와 제외 이유
- 프로젝트별 권장 페이지 수
- `templates/05-deck-plan.md`의 선택 소재 표 (방식 1은 `PPT 초안` 페이지 본문에, 방식 2는 `workspace/_jobs/<job>/05-deck-plan.md`에 기록하고 속성 블록의 `선택_소재`에 파일 경로를 적음)
