# 기존 PPT 기반 초안 생성 프롬프트

입력:

- 기존 PPTX
- 승인된 포트폴리오 소재 (프로필 `templates/00-profile.md`, 작업 방식 `templates/06-work-process.md` 포함)
- 구성표: 방식 1은 Notion `PPT 초안` 페이지, 방식 2는 `workspace/_jobs/<job>/05-deck-plan.md` (양식 `templates/05-deck-plan.md`)
- `references/portfolio-writing-guide.md`
- `references/ppt-application.md`
- `design/layout-spec.md`
- `design/design-tokens.md`
- 현재 포트폴리오 형식으로 만들거나 페이지를 늘릴 때 `design/tokens-current-deck.md`
- 사용자가 디자인 변경을 요청한 경우에만 `design/design-options.md`

작업 순서:

1. 기존 PPT의 슬라이드 수와 텍스트 영역을 확인한다.
2. 페이지마다 어떤 소재와 메시지를 넣을지 구성표를 먼저 제시한다. 레이아웃 ID와 목차 쪽 범위를 함께 적는다.
3. 페이지별 원고를 `[N페이지]` 형식으로 작성하고, 페이지마다 발표자 노트 원고를 붙인다.
4. 사용자가 페이지 단위 검토를 요청하면 한 장씩 설명하고 승인된 문구만 반영한다.
5. 작업 모드를 정한다. 사용자가 허용한 모드 밖의 변경은 하지 않는다.
   - `text-only` (기본): 승인된 텍스트만 교체. 슬라이드 수·순서·도형·이미지·스타일 유지
   - `rebuild-from-template`: 템플릿 슬라이드를 복제·삭제해 프로젝트 수와 트러블슈팅 수에 맞게 페이지 구성
   - `diagram`: 도식·차트·로고를 편집 가능한 PPT 도형과 기본 차트로 만들거나 고침
6. 전체 승인 후 `_수정전백업` 사본을 만들고, 최신 파일을 다시 읽은 뒤 정한 모드대로 반영한다. 사용자가 직접 고친 부분은 되돌리지 않는다.
7. 텍스트 상자 위치는 렌더링이 아니라 계산으로 정한다. Pretendard 글자 폭으로 문단마다 줄 수를 계산하고, `tokens-current-deck.md`의 간격 규칙으로 상자를 쌓는다. LibreOffice 렌더링은 한글과 영문·숫자 사이에 빈칸을 더 넣어 PowerPoint와 줄바꿈이 다르므로, 렌더링은 겹침·누락·이미지 깨짐 확인에만 쓴다.
8. 저장 후 파일을 다시 읽어 저장된 내용과 바뀐 슬라이드 범위를 확인하고, 구성표의 `상태`·`확인_방법`·`최종_검증일`을 고친다 (방식 1은 Notion 속성, 방식 2는 속성 블록).
9. 서로 맞아야 하는 값을 대조한다: 목차 쪽 범위 ↔ 실제 페이지, 노트 `[N페이지]` ↔ 실제 페이지, 차트 값 ↔ `03-1 결과`·회고 본문, 제목·본문·도식 용어.
10. 최종 PPT에서 텍스트를 다시 추출해 승인 원고와 대조한다.
11. 완료 보고에 PowerPoint 화면으로 확인했는지, 렌더링과 줄 수 계산으로만 확인했는지 구분해 적는다.

디자인 적용 규칙:

- 레이아웃 명세는 페이지별 정보 영역과 좌표를 정할 때 사용
- 디자인 토큰의 기본 모드는 `preserve-existing`
- 기존 PPT가 있으면 기존 글꼴·크기·굵기·색상·간격 유지
- 현재 포트폴리오 형식으로 새 페이지를 만들 때는 `tokens-current-deck.md` 값 적용
- 디자인 옵션은 사용자가 명시적으로 선택한 경우에만 적용

문구 규칙:

- 표지 소개 문구를 제외하고 명사형 어미 사용
- 제목은 `프로젝트명: 결과 또는 수치` 형식
- 기술명보다 문제, 판단, 변화, 검증을 먼저 제시
- 클래스명·변수명 같은 코드 내부 용어를 본문 핵심어로 사용하지 않음. 단, 결과를 증명하는 HTTP 상태 코드·오류 코드는 제목과 본문에 허용하고 처음 나올 때 의미를 한 번 풀어 씀
- 결과 수치에 비교 대상과 측정 대상 유지
- 직접 기여와 팀 성과 분리
- 트러블슈팅은 회귀·사이드 이펙트 확인 결과(확인된 결과만)로 끝내고, 남은 한계는 노트로 보냄
- 원고가 길면 설명을 압축하되 근거와 기술적 의미를 삭제하지 않음
- 가이드의 예시 문구와 프로젝트 용어 재사용 금지

원본 PPT의 디자인, 이미지, 도형 배치는 `text-only` 모드에서는 변경하지 않는다.
