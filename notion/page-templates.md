# Notion 페이지 템플릿 배치

Notion의 데이터베이스 템플릿 기능으로 아래 종류를 등록한다.

## 프로젝트 기본 템플릿

- `templates/01-project-overview.md` 본문 삽입
- 하단에 현재 프로젝트로 필터링한 `포트폴리오 소재` 연결 뷰 배치
- 소재 뷰는 `유형`으로 그룹, `순서` 오름차순

## 담당 기능 소재 템플릿

- `templates/02-my-contribution.md` 삽입
- 기본 유형: `담당 기능`
- 기본 상태: `자료 수집`
- 기여 형태는 자동 선택하지 않고 작성자가 확인

## 트러블슈팅 소재 템플릿

- `templates/03-troubleshooting.md` 삽입
- 기본 유형: `트러블슈팅`
- 기본 상태: `자료 수집`
- 문제 발생 성격과 증거 수준은 초안 생성 후 직접 확인

## 회고·성과 소재 템플릿

- `templates/04-retrospective-outcomes.md` 삽입
- 기본 유형: `회고·성과`
- 직접 성과와 팀 전체 성과 섹션 유지

## 이력·목차 소재 템플릿

- `templates/00-profile.md` 삽입
- 기본 유형: `이력·목차`
- `프로젝트` 관계는 비움
- 목차 항목은 PPT 초안의 쪽 범위가 정해진 뒤 채움

## 작업 방식 소재 템플릿

- `templates/06-work-process.md` 삽입
- 기본 유형: `작업 방식`
- `프로젝트` 관계는 비움
- 단계별 근거는 발표자 노트 섹션에 유지

## PPT 초안 템플릿

- `templates/05-deck-plan.md` 삽입
- 기본 상태: `소재 선별`
- 선택 소재 관계가 채워진 뒤 페이지 구성 작성
- `검증 완료`로 바꾸기 전에 `확인 방법`을 기록

템플릿 본문을 줄이더라도 사실 근거, 기여 형태, 회귀 확인, 확인 필요 섹션은 제거하지 않는다. 트러블슈팅의 회귀·사이드 이펙트 확인 결과는 필수이고, 영향과 한계 섹션은 슬라이드에 쓰지 않는 노트용으로 남긴다.
